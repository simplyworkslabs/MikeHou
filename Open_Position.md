Position Summary	
This temporary position provides short-term support for data engineering, data integration, data modeling, and business intelligence activities within the School of Medicine Information Technology department. The role focuses on developing and supporting reliable data pipelines, curated data layers, and Power BI solutions using SQL Server and Azure-based data platforms such as Microsoft Fabric or Azure Databricks.

Essential Duties and Responsibilities:

* Develop, maintain, and optimize SQL Server queries, views, functions, and stored procedures in support of operational and reporting needs.
* Perform data validation, reconciliation, and quality checks across source, transformation, and curated data layers.
* Assist with data extraction, transformation, and loading (ETL) processes using Informatica (IICS), SSIS, or comparable ETL tools.
* Support integration of data from multiple source systems into SQL Server environments.
* Optimize SQL queries, transformations, data pipelines, and reporting datasets under the guidance of senior technical staff.
* Develop, maintain, and support Power BI reports, dashboards, semantic models, and data refresh processes using approved reporting and analytics tools.
* Support data ingestion and transformation workflows that prepare curated data for Power BI reporting using Azure-based platforms, including Microsoft Fabric or Azure Databricks.
* Work with lakehouse and medallion architecture patterns, including Bronze, Silver, and Gold data layers, to support reliable and reusable reporting datasets.
* Assist with Power BI data modeling, DAX measures, Power Query transformations, row-level security, refresh troubleshooting, and report performance optimization.
* Prepare and maintain documentation for source-to-target mappings, data pipelines, transformation logic, curated datasets, semantic models, and scheduled processes.
