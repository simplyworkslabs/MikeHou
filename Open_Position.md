We currently have an opening for an Applications Systems Analyst II


The Applications Systems Analyst II position in the NCDIT-Transportation Engineering Applications Development Unit provides a challenging and exciting opportunity to be a member of the Application Development Team responsible for maintaining custom software used by the North Carolina Department of Transportation for bridge inspections.

In this role, responsibilities range from writing code for bridge inspection tools to assisting business units with data requests, reporting, and operational support.

Duties include, but are not limited, to:
• Develop and maintain highly complex program source code for applications in high level languages such as C# and Structured Query Language (SQL)
• Develop and maintain SQL Anywhere 17 database schemas, publications, and subscriptions for data distribution to remote inspection teams
• Manage Mobilink synchronization scripts to support offline-capable field applications
• Write, optimize, and analyze complex SQL queries for data synchronization, reporting, and data analysis
• Analyze SQL query performance and recommend optimizations
• Provide technical support and problem resolution for business units and end users of the bridge inspection software


About the Division:
The primary purpose of the Engineering Applications Development Unit is to coordinate and direct the planning, development, or procurement, installation and operation of information systems for the various Highway Division Branches and Units.
Knowledge Skills and Abilities/Management Preferences
